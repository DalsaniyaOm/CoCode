CoCode is a zero-installation, browser-based collaborative code editor developed as a Capstone Prototype for the Computer System Technology program at Sheridan College. It allows multiple users to write, edit, and review code simultaneously in real-time without merge conflicts or screen-share lag.

## 🛠️ Tech Stack

* **Frontend:** React (via Vite), Tailwind CSS, Monaco Editor
* **Backend:** Node.js, Express.js
* **Real-Time Sync:** Socket.io, Yjs (CRDT Algorithm)
* **Database:** MongoDB Atlas (Mongoose)
* **Security:** JSON Web Tokens (JWT), bcrypt

## 💻 Local Development Setup

Ensure you have the following installed on your developer machine:
* [Node.js](https://nodejs.org/) (v18 or higher)
* [Git](https://git-scm.com/)
* [MongoDB Compass](https://www.mongodb.com/products/tools/compass) (Optional, for viewing the database locally)
